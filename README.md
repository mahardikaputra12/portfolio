# Portfolio Mahardika Putra Qohar

Vite + React. Konten ada di `src/data.js` dan `src/App.jsx`, gaya di `src/styles.css`.

    npm install
    npm run dev      # jalankan lokal di http://localhost:5173
    npm run build    # hasil build ada di folder dist

Deploy: push ke repo `mahardikaputra12.github.io`, lalu di Settings > Pages pilih Source "GitHub Actions".
